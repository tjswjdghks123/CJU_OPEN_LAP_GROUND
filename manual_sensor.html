직접 입력한 변화 이력으로 가상 전조 패턴 점수를 계산합니다. 합성 데이터로 학습한 모델이며 실제 낙뢰 발생 확률·발생 시각은 확인할 수 없습니다. 입력을 올려도 낙뢰 사건을 자동으로 만들지 않습니다. 실제 장비 연결·제어는 없습니다.

1. 입력값 조절

누설전류는 mA로 입력합니다. 처음 값은 예시이며 자유롭게 바꿀 수 있습니다. 숫자만 수정하면 아직 저장되지 않고, 아래 추가 버튼 또는 자동 입력으로 이력에 반영됩니다.

각 행은 1초 간격의 실험 입력입니다. 30초 채우기는 같은 값을 반복한 합성 이력입니다. 첫 행은 누적 횟수 기준값이므로 최초 점수에는 31행(0~30초)이 필요합니다. 자동 입력은 브라우저 지연 시 실제 시계와 다를 수 있습니다.

CSV 입력 이력 올리기

양식의 영문 열 이름과 단위를 유지하세요. CSV의 leakage_current는 A 단위(2mA = 0.002A)입니다. time_s는 1초 간격 정수이며 최대 2000행입니다. 업로드는 현재 이력 뒤에 추가합니다. 다른 실험 파일은 먼저 초기화하세요. 모든 행을 최신 입력으로 간주하며 실제 센서 수집 상태는 검증하지 않습니다.

3. 사건 기록과 예측 자동 평가

사건은 정답 대조용 기록이며 모델 입력에 넣지 않습니다. ‘현재 시각에 가상 사건’은 실제 낙뢰가 아닙니다. 외부 관측 파일도 출처·동일 장소·시간 동기화·정답 완전성을 별도로 확인해야 하며 업로드만으로 실제 성능이 검증되지는 않습니다.

CSV 열: time_s,kind,source · kind: virtual 또는 observed. 날짜 문자열이 아니라 센서 CSV와 동일 기준의 정수 초를 사용하세요. 같은 종류의 같은 초 감지는 하나의 사건으로 묶습니다. 누적 횟수 증가를 자동으로 정답으로 삼지 않습니다.

사건 기록 후 자동 평가를 실행하세요.

사건 t초의 직전 [t−10,t) 10개 점수가 모두 있을 때만 적중률 분모에 포함합니다. 사건 시각 또는 이후 경보는 사전 적중이 아닙니다. 사건보다 10초 넘게 이른 경보도 이번 목표의 적중이 아닙니다. 오경보는 다음 10초의 사건이 없는 예측 창 중 경보한 비율이며, 연속 구간은 보기 편하게 묶습니다. 기록 끝의 미래 10초가 확인되지 않은 창은 제외합니다. 평가 시 자동 입력은 멈춥니다. 입력·사건 변경 후에는 다시 평가하세요. 결과 JSON에 입력·점수·사건·평가가 함께 저장됩니다.
