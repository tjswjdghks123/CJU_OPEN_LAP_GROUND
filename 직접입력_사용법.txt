센서 10개 직접 입력 실험실

VS Code의 ground 폴더 터미널에서:
.\.venv\Scripts\python.exe ground.py --manual

기존 시나리오 재생은 ground.py만 실행하면 그대로 유지됩니다.
직접 입력 화면: http://127.0.0.1:8769/
이 서버는 자신의 PC에서만 접속할 수 있고 외부 서버나 회사 장비에 연결하지 않습니다.
종료는 터미널에서 Ctrl+C입니다.

1. 현재 값으로 30초 채우기를 누르고, 현재 값 1초 추가를 누르면 첫 점수가 나옵니다.
2. 1초마다 자동 입력을 시작하고 숫자를 수정하면 변경된 값이 다음 행부터 반영됩니다.
3. 대지전위 a/b와 누설전류를 조금씩 올리거나 내리며 반응을 비교하세요.
4. 파란 선은 입력 이력으로 실제 계산한 LSTM 점수이고 점선은 기존 고정 경보 기준입니다.
5. CSV 양식 받기로 영문 열 이름을 확인하고 1초 간격 이력을 업로드할 수 있습니다.
6. 입력·결과 JSON 저장으로 전체 실험을 보관하세요. 초기화·새로고침 시 이력은 사라집니다.

화면 누설전류 단위는 mA, CSV 단위는 A입니다. 2mA는 CSV에서 0.002입니다.
CSV는 최대 2000행이며 다른 시간축의 파일은 먼저 초기화하세요.
시간 누락이나 누적 횟수 감소 시 입력 창을 다시 모읍니다.
각 행은 사용자가 제공한 최신 값으로 가정합니다. 실제 통신·수집 주기 검증은 아닙니다.
입력 범위는 기존 프로그램 검증 범위를 유지하며 실제 장비 허용 범위의 확정 자료가 아닙니다.

모델은 합성 데이터로 학습했습니다. 출력은 가상 전조 패턴 점수이고 실제 낙뢰 확률이 아닙니다.
점수가 낮아도 실제로 안전하다는 뜻은 아닙니다. 입력에 따라 낙뢰 정답을 자동 생성하지 않습니다.
누적 횟수는 직접 제공하는 관측/실험 입력입니다. 예측된 미래 횟수가 아닙니다.
이번 기능은 모델 재학습이나 실제 낙뢰 예측 성능 검증을 의미하지 않습니다.

[사건 기록·자동 평가 추가]
화면 아래 3번 영역에서 사건 시각을 입력하거나 현재 시각에 가상 사건을 기록합니다.
사건 CSV는 time_s,kind,source 열이며 kind는 virtual 또는 observed입니다.
사건 시각은 센서 이력과 같은 기준의 정수 초여야 합니다. 같은 초·종류 사건은 하나로 묶습니다.
사건 기록은 모델 입력에 들어가지 않으며 이미 계산한 점수를 바꾸지 않습니다.
자동 평가 실행: 사건 직전 10개 점수가 모두 있을 때 적중/누락을 평가합니다.
사건 시각 및 이후의 경보는 적중이 아닙니다. 10초보다 먼저 발생한 경보도 이번 목표에서 제외됩니다.
동일 경보가 10초 안의 여러 사건에 적중할 수 있으므로 사건 재현율을 경보 정밀도로 해석하지 마세요.
오경보는 사건 목록이 빠짐없는 구간을 지정하고 확인한 경우에만 계산합니다.
여기서 오경보 비율은 무사건 예측 창 중 경보 창의 비율이며 경보 중 틀린 비율과 다릅니다.
기록 끝에서 미래 10초를 확인할 수 없는 예측은 오경보 집계에서 제외합니다.
외부 관측 기록도 사용자가 제공한 미검증 자료로 분리합니다. 실제 낙뢰 성능 인증이 아닙니다.
입력·결과 JSON 저장에 사건과 평가가 함께 저장됩니다. 평가 후 입력/사건 변경 시 다시 평가하세요.
자동 테스트 33개 통과. 브라우저에서 가상 사건 기록·누락 평가·완전성 확인 오경보 계산을 확인했습니다.
