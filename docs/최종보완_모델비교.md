훈련 시드 410000번대 / 검증 510000번대 / 최종 시험 610000번대. 모델 구조와 30시점은 유지하고 학습 데이터 및 학습 전용 Min-Max를 새로 구성했습니다.
가중치는 검증 손실, 경보 기준은 검증 F1 및 음성 창 오경보율 1% 제한으로 선택했습니다. 최종 시험은 선택에 사용하지 않았습니다.
같은 모델 구조라도 모든 조건에서 개선되는 것은 아닙니다. 감지와 오경보를 함께 보고 개선 후보 채택을 판단해야 합니다.
상승 후 회복과 실제 가상 사건 패턴은 초기 구간이 유사하여 오경보가 발생할 수 있습니다. 실제 전조 물리량의 근거는 아닙니다.

재현: python improve_showcase.py --output 새로운_출력폴더 --epochs 20
새 모델: week6_improved_bundle/count_model.keras. 기본 5주차 시연은 기존 모델 결과를 유지하며 비교 화면에서 후보 결과를 따로 보여줍니다.

## 남은 한계
전체 음성 창 오경보율은 0.59% → 1.16%로 증가했습니다. 개선 모델의 오경보 460개 창 중 458개는 사건보다 10초 넘게 이른 경보이고 2개는 무사건 회복 사례입니다. 감지 민감도는 개선됐지만 다음 10초라는 시간 범위의 정확성은 개선 과제로 남습니다.
이전 0/30 시험과 이번 2/30 시험은 약한 패턴의 진폭·속도·난수 구성이 다릅니다. 같은 시험 결과가 바뀐 것이 아닙니다.

## 발표에서 읽을 설명
5주차에서는 가상 전조의 기본 패턴을 감지했지만 약한 패턴을 놓쳤습니다. 이번에는 입력 센서와 모델 구조를 유지하고, 학습 데이터에 다양한 상승 폭과 속도 및 회복 사례를 추가했습니다. 별도로 분리한 새로운 시험 데이터에서 기존 모델과 비교한 결과, 약한 사건 감지는 2건에서 29건으로, 느린 사건 감지는 2건에서 30건으로 개선됐습니다. 회복 사례의 오경보는 25건에서 1건으로 줄었습니다. 다만 사건보다 너무 이른 경보가 늘어 다음 10초라는 예측 시간 범위에는 한계가 남았습니다. 이 결과는 합성 데이터에서의 개선이며 실제 낙뢰 예측 성능은 검증하지 못했습니다.
