# 6주차: 센서 10개 기반 경보·모의 보호 통합 시연

## 실행

프로젝트 폴더에서 `.\.venv\Scripts\python.exe ground.py`를 실행한다. 기본은 30개 시드 × 4개 조건 × 5개 상황 = 600개 사례이며 계산 시간이 필요하다. 빠른 기능 확인은 `--seed-count 1`을 추가한다. 기존 보고서 시연 5개는 별도로 유지한다.

## 입력과 모델

대지전위 a/b, 누설전류, 제한소자 온도 a/b/c, 상대습도, 외기온도, 입력전압, 누적 낙뢰 횟수의 10개 입력을 그대로 사용한다. 기존 학습 전용 Min-Max, 30개 시점, 저장된 LSTM과 경보 기준을 유지했다. 이번 변경은 재학습이나 실제 낙뢰 예측 성능 개선이 아니다.

## 네 조건 비교

같은 시드를 조건별로 짝지어 비교한다. 신호 60%는 가상 사건 전 전위·누설의 동반 증가 폭만 조절한다. 잡음 2배는 생성기의 대지전위·누설전류·입력전압 잡음에 적용되며 온습도 잡음 전체를 두 배로 만든 것은 아니다. 약한 신호만 바꾼 조건의 사건 없는 사례는 기본 조건과 같으므로 600개를 모두 독립 표본이라고 해석하지 않는다.

| 조건 | 가상 사건 경보 | 놓친 사건 | 초 단위 재현율 | 사건 없는 사례 경보 |
|---|---:|---:|---:|---:|
| 기존 합성 규칙 · 난수 변화 | 30/30 | 0 | 96.67% | 0/120 |
| 약한 신호만 · 잡음 동일 | 0/30 | 30 | 0.00% | 0/120 |
| 잡음만 2배 · 신호 동일 | 30/30 | 0 | 95.33% | 0/120 |
| 약한 가상 전조 · 잡음 증가 | 0/30 | 30 | 0.00% | 0/120 |

위 표는 LSTM 점수가 사건 직전 10초 내 기준을 넘었는지를 평가한다. 연속 3회 조건을 거친 모의 보호 요청 성공률과는 다르다. 점수가 올라가도 기준을 넘지 않으면 사건 경보 성공으로 세지 않는다. 원자료·정답이 합성이므로 실제 낙뢰 예측 성능을 증명하지 않는다.

## 모의 보호 동작

입력 수집 → 대기 → 연속 경보 확인 → 모의 보호 요청 → 모의 응답 확인·유지.

기준 이상 3회 연속일 때 모의 요청을 만들고, 가상 응답기는 1초 후 응답한다. 3초가 되도록 응답이 없으면 TIMEOUT이다. 정확히 3초에 도착한 응답도 늦은 응답으로 처리한다. 설정값은 실습용이며 업체 장비 사양이 아니다. 실제 차단, 전압 변경, 통신 명령은 없고 전압 0V 달성이나 실제 보호 효과를 확인한 것이 아니다.

오류·응답 완료 상태는 유지된다. 다른 상황 선택 또는 처음부터 재생하면 저장된 시뮬레이션을 처음부터 보여준다. 실제 장비 재가동 명령은 없다.

기존 가상 전조 고정 시드의 상태 전이: 30초 NORMAL → 115초 WARNING → 117초 REQUESTED → 118초 PROTECTED_SIM

## 오류 처리 시험

모의 응답 정상, 응답 없음, 센서 누락 주입, 시간 누락 주입을 별도 시험한다. 이 네 시험은 경보 점수를 직접 넣는 제어 로직 시험이며 LSTM이 오류를 예측한 시험이 아니다. 입력 오류와 응답 시간 초과는 잠금 상태를 유지한다. 그래프 아래 접힌 오류 시험 결과에서 확인할 수 있다.

`protection_log.json`에는 모든 조건의 모의 상태 전이와 오류 시험 결과가 저장된다. `seed_evaluation.json`과 PNG에는 모델 경보 평가가 저장된다.

## 시연 순서

1. 정상과 과열을 비교해 장비 기준 초과와 LSTM 경보를 구분한다.
2. 기존 가상 전조를 110초 부근부터 재생해 점수 상승, 연속 경보, 모의 요청과 응답을 보여준다.
3. 같은 시드의 약한 신호만, 잡음만 증가, 두 조건 결합을 비교한다.
4. 모의 보호 동작 아래 오류 시험 결과와 로그를 보여준다.
5. 실제 낙뢰 사전 예측과 실제 보호 효과는 아직 검증 전임을 설명한다.

## 검증

기존 입력·모델 검사 17개와 모의 제어 검사 5개, 총 22개 테스트 통과. 전체 600개 사례의 상태 이력과 무명령 기록, 4개 오류/응답 예제를 추가 확인했다. 최종 그래프의 수치는 저장된 계산 결과다.
